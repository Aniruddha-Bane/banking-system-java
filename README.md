# 🏦 Bank Account Simulator (Java)

A backend-style Java console application that simulates banking operations with file-based persistence and transaction history.

---

## 🚀 Features

- Create Bank Account (in-memory)
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History Logging
- File-based Data Persistence
- Encapsulated OOP Design
- Service Layer Architecture

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Encapsulation
- File Handling (Persistence)
- Service Layer Architecture
- Separation of Concerns
- Business Logic Design
- Transaction Logging System

---

## 🏗️ Project Structure

src/com/bankapp/
├── main
├── model
├── service
└── util

---

## 📂 Data Storage

- accounts.txt → stores account data
- transactions.txt → stores transaction logs

---

## ▶️ How to Run

1. Open in IntelliJ IDEA
2. Run Main.java
3. Use terminal menu
